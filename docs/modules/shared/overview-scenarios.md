# OWL Scenarios Overview

The canonical product-level use case catalog is
[OWL Use Case Catalog and User Journeys](../../design/active/use-case-catalog-and-user-journeys.md).
It defines:

- the boundary among Paperless-ngx, OWL, Mission Control, Tyrion, and
  acquisition tools;
- the distinction among Inbox filing, Needs Review, Action Queue, and
  recurring-document monitoring;
- the Organize, Watch, and Learn use case catalog;
- seven primary end-to-end journeys;
- current frontend route coverage; and
- prioritized journey breakdowns and prototype risks.

Module documents in this section remain the authority for detailed behavior.
This overview intentionally does not maintain a second feature or status list,
because those details change more frequently than the user journeys.

# Contributing

Thank you for your interest in OWL. The source and issue tracker are public,
but development is maintained against an internal backlog and unsolicited
external code contributions are not accepted.

Please do not open a pull request unless a maintainer has invited the specific
change. Unsolicited pull requests will be closed so the maintainers can keep
the project's scope and review obligations predictable.

You may open an issue for a reproducible defect or concise project feedback.
Before doing so, search existing issues, exclude secrets and personal
documents, and include only the minimum reproduction details needed. Issues
are not a support channel; see [SUPPORT.md](SUPPORT.md). Report suspected
vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
